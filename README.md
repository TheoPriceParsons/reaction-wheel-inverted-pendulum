# Reaction Wheel Inverted Pendulum

## Overview
Modeling and control of a reaction-wheel inverted pendulum,
with the goal of stabilizing the upright equilibrium.

## System Description
A rigid pendulum with an actuated reaction wheel at the base.
The control input is motor torque applied to the wheel.

## Modeling Approach
Equations of motion derived using Lagrangian mechanics.
The system is linearized about the upright equilibrium (θ = 0).

## Current Status
- Equations of motion derived
- Linearization completed
- State-space formulation in progress

## Next Steps
- Derive linear state-space model
- Design feedback controller (LQR)
- Simulate open-loop and closed-loop behavior
